# LifePath Simulator

LifePath Simulator is a browser-based life simulation game built with HTML, CSS, and JavaScript.

Players choose a birth background and see how different choices affect their character's starting stats, such as English, Math, Stress, and Money.

## Current Version

v0.1

## Features

- Choose a birth background
- Display starting character stats
- Basic HTML, CSS, and JavaScript structure
- Development log included

## Tech Stack

- HTML
- CSS
- JavaScript

## Development Log

I am building this project step by step while learning web development.

The long-term goal is to turn this into a more advanced life simulation system with choices, events, different paths, and eventually AI-generated reports.
